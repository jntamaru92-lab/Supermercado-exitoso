# Instrucciones para agentes (Codex y otros)

Este repositorio contiene skills de periodismo digital para **Contrastes TV**.

1. Lee primero `CLAUDE.md`: ficha de marca y reglas editoriales globales. Son obligatorias.
2. Las skills están en `.claude/skills/<nombre>/SKILL.md`. Antes de una tarea, revisa el campo `description` de cada una y carga la que corresponda.
3. Aplica siempre `voz-de-marca` y, si hay datos de terceros, `verificacion-fact-checking`.
4. No publiques nada directamente en redes ni en la web: entrega borradores para aprobación humana.
