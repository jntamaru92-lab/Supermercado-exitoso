# Adaptación multiplataforma

**Principio:** una historia, muchas formas. Nunca copiar y pegar el mismo texto en todas las redes.

## 1. Partir de la pieza madre

Identifica en la noticia:
- **Idea fuerza** (1 frase).
- **3 datos clave.**
- **Mejor imagen o momento de video.**
- **El contraste** (la otra mirada o el dato que cambia la lectura).
- **Utilidad:** ¿qué debe saber o hacer la audiencia?

## 2. Matriz por plataforma

| Red | Formato prioritario | Texto | Enlace |
|---|---|---|---|
| **Web** | Nota completa (pieza madre) | `redaccion-seo-noticias` | — |
| **X** | Post corto o hilo de 3–6 posts | Dato + atribución; hilo para explicadores | Sí, en el 1.er post o al final del hilo |
| **Threads** | Post conversacional | Pregunta o dato + contexto | Opcional |
| **Facebook** | Post con enlace o video nativo; Reels | 2–4 líneas cercanas + pregunta | Sí (en post con vista previa) |
| **Instagram** | Carrusel (explicadores), Reel (noticia), Historias (último momento, encuestas) | Caption: gancho + desarrollo + contraste + CTA | Enlace en bio o sticker en historias |
| **TikTok** | Video vertical | `guion-video-vertical` | Enlace en bio |
| **YouTube** | Short + video largo (nota de TV completa, entrevista, análisis) | Título SEO, descripción con capítulos | Sí, en descripción |
| **WhatsApp Channel** | Mensaje breve con enlace | `newsletter-y-whatsapp` | Sí |
| **LinkedIn** | Post analítico (economía, empresa, tecnología, trabajo) | Dato + implicación profesional | Sí, en comentario o post |

## 3. Plantillas

### Hilo de X
```
1/ [Dato o hecho principal + atribución]. Te explicamos lo que significa 🧵
2/ Qué pasó: …
3/ Por qué importa: …
4/ 🔄 El contraste: …
5/ Qué sigue: …
6/ Nota completa 👉 [enlace]
```

### Carrusel de Instagram (6–10 láminas, 1080×1350)
```
Lámina 1: Titular grande (3–8 palabras) + imagen. Es la portada: debe detener el scroll.
Lámina 2: Qué pasó (1 frase + dato).
Láminas 3–5: Un dato o idea por lámina, con número grande o ícono.
Lámina 6: 🔄 El contraste.
Lámina 7: Qué hacer / qué sigue.
Lámina final: Logo + «Guárdalo y compártelo» + @usuario.
```
Regla: máx. 30 palabras por lámina, tipografía de marca, contraste alto.

### Post de Facebook
```
[Gancho de 1 línea]
[2–3 líneas de contexto, cercanas]
🔄 [El contraste en una línea]
¿Ustedes qué opinan? 👇
[enlace]
```

### Descripción de YouTube
```
[2 líneas con palabra clave principal]
⏱️ Capítulos:
00:00 Introducción
00:35 …
🔗 Nota completa: [enlace]
📲 Síguenos: [redes]
#tema #ciudad #ContrastesTV
```

## 4. Orden de publicación sugerido

1. **Último momento:** X/Threads → WhatsApp → web → historias IG/FB → video vertical.
2. **Noticia planificada:** web → Facebook + X → Reel/TikTok → carrusel → WhatsApp/newsletter.
3. **Explicador / evergreen:** web → carrusel → video vertical → YouTube → reciclar a los 30–60 días.

Escalonar 15–60 minutos entre redes para no competir consigo mismo y poder reaccionar a los primeros resultados.

## 5. Formato de entrega

Entregar todas las piezas en un solo documento, separadas por red, cada una lista para copiar, con: texto, indicación visual, hashtags, enlace y horario sugerido. Cerrar con el bloque `— CONTROL EDITORIAL —`.
