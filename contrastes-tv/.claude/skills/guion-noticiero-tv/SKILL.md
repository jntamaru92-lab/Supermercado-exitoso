# Guion de noticiero y notas de TV

## 1. Escribir para el oído

- Frases de **máximo 15–18 palabras**, sujeto-verbo-predicado.
- Una cifra por frase, redondeada cuando no cambie el sentido: «casi 3 000» en vez de «2 987».
- Atribución **al inicio**: «Según la policía, …».
- Tiempo presente o pretérito reciente: «La alcaldía anuncia…», «Esta mañana…».
- Evitar siglas poco conocidas, paréntesis y citas largas.
- Lectura: ~**2,5 palabras por segundo** (150 por minuto) para calcular duraciones.

## 2. Formatos de pieza

| Código | Qué es | Duración típica |
|---|---|---|
| **PRES** | Presentación del conductor/a en cámara | 10–20 s |
| **VO** (voz en off) | Conductor/a lee sobre imágenes | 20–30 s |
| **VO/SOT** | VO + declaración (sound on tape / «totales») | 30–45 s |
| **PKG** (nota armada) | Nota completa del reportero: off + totales + stand-up | 1:15–2:00 |
| **LIVE / DIRECTO** | Enlace con reportero/a en terreno | 1:00–3:00 |
| **GFX** | Gráfico a pantalla completa con locución | 10–20 s |

## 3. Guion a dos columnas

```
NOTA: [slug]          FORMATO: PKG        DURACIÓN: 1:30
REPORTERO/A:          CÁMARA:             EDITOR/A:

| VIDEO                                   | AUDIO                                         |
|-----------------------------------------|-----------------------------------------------|
| PRES conductor/a                        | (Conductor/a) Texto de presentación…          |
| Imágenes de la avenida bloqueada        | (Off) Desde las seis de la mañana…            |
| ZÓCALO: Nombre Apellido / Cargo         | (SOT) "Cita textual…" (0:12)                  |
| GFX: cifra clave                        | (Off) Según el ministerio, …                  |
| ZÓCALO: Nombre / Vecino de [barrio]     | (SOT) "Cita de la otra parte…" (0:10) ← CONTRASTE |
| Stand-up del reportero/a                | (Stand-up) Mañana se reúnen…                  |
| Cierre                                  | (Off) Para Contrastes TV, [Nombre], [ciudad]. |
```

## 4. Estructura de la nota armada (PKG)

1. **Arranque visual** con la mejor imagen y sonido ambiente (2–3 s).
2. **Off 1:** qué pasó y por qué importa.
3. **Total 1:** protagonista o afectado.
4. **Off 2:** contexto y datos.
5. **Total 2:** la otra parte / autoridad / especialista — **el contraste**.
6. **Stand-up:** lo que viene o un dato que no tiene imagen.
7. **Cierre** con firma.

## 5. Escaleta del noticiero

```
NOTICIERO: [nombre]   FECHA:   DURACIÓN TOTAL:

| # | Bloque | Tema | Formato | Duración | Acumulado | Responsable | Estado |
|---|--------|------|---------|----------|-----------|-------------|--------|
| 1 | A | Apertura / titulares | PRES+VO | 0:45 | 0:45 | | |
| 2 | A | Nota principal | PKG | 1:45 | 2:30 | | |
| … | | | | | | | |
|   | — | PAUSA COMERCIAL | | 2:00 | | | |
```

Orden recomendado: titulares → noticia más importante → noticias relacionadas → bloque local/servicio → pausa → nacional/internacional → economía → deportes/espectáculos → cierre con historia humana o «El Contraste».

## 6. Zócalos (lower thirds)

- Línea 1: **Nombre Apellido** (verificar ortografía).
- Línea 2: cargo o relación con la noticia, ≤ 35 caracteres.
- Zócalo temático: ≤ 45 caracteres, en presente: «Vecinos bloquean avenida por falta de agua».

## 7. TV → digital

Toda nota de TV debe tener vida digital: recortar el PKG a vertical (`guion-video-vertical`), subir completo a YouTube con título SEO y enlazarlo en la nota web.
