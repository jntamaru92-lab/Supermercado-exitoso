# Redacción SEO de noticias

**Principio:** se escribe para personas y se estructura para buscadores. Google premia la experiencia, el conocimiento, la autoridad y la confianza (E-E-A-T): firma real, fuentes citadas, información original.

## 1. Antes de escribir

1. **Intención de búsqueda:** ¿qué escribiría alguien en Google para encontrar esto? Ej.: «paro de transporte hoy [ciudad]», «cuándo pagan el bono».
2. **Palabra clave principal** (1) y **secundarias** (2–4, variantes y preguntas).
3. **Tipo de nota:**
   - *Noticia caliente* → velocidad, Google News / Top Stories.
   - *Explicador / servicio* (evergreen) → búsqueda sostenida en el tiempo.
   - *Historia visual / humana* → Google Discover.

## 2. Estructura de la nota

```
TITULAR SEO (H1)          55–70 caracteres, palabra clave al inicio
BAJADA / SUMARIO          1–2 frases, amplía el titular, no lo repite
PRIMER PÁRRAFO (lead)     qué, quién, cuándo, dónde + palabra clave, 35–50 palabras
2.º PÁRRAFO               por qué importa / contexto
H2: ¿Qué pasó?            desarrollo de los hechos
H2: ¿Qué dicen las partes? ← el CONTRASTE de la marca
H2: [pregunta frecuente]  ej. «¿Cuándo se paga?», «¿A quién afecta?»
H2: ¿Qué sigue?           próximos pasos, fechas
CAJA "Claves"             3–5 viñetas para lectura rápida
ENLACES RELACIONADOS      2–4 notas propias
FIRMA + FECHA Y HORA DE ACTUALIZACIÓN
```

Longitud orientativa: noticia caliente 300–600 palabras; explicador 800–1500.

## 3. Elementos SEO a entregar

| Elemento | Regla |
|---|---|
| **Titular H1** | Claro, con la palabra clave al inicio, sin clickbait. |
| **Título SEO (title tag)** | ≤ 60 caracteres + « \| Contrastes TV». Puede diferir del H1. |
| **Meta descripción** | 140–155 caracteres, con palabra clave y un motivo para hacer clic. |
| **URL (slug)** | Corta, minúsculas, guiones, sin fechas ni palabras vacías: `/local/paro-transporte-ciudad-lunes`. |
| **Subtítulos H2/H3** | Cada 150–300 palabras; usar preguntas reales de la audiencia. |
| **Imagen destacada** | Propia o licenciada, mínimo 1200 px de ancho (requisito para Discover), horizontal 16:9. |
| **Texto alternativo (alt)** | Describe la imagen e incluye contexto: «Buses detenidos en la avenida Central durante el paro». |
| **Enlaces internos** | 2–4 a notas propias relacionadas, con texto ancla descriptivo. |
| **Enlaces externos** | A la fuente primaria (decreto, estudio, comunicado oficial). |
| **Etiquetas / tags** | 3–6, consistentes con las que ya usa el sitio. |
| **Datos estructurados** | `NewsArticle` (titular, imagen, fechas, autor). Si hay en vivo, `LiveBlogPosting`. |

## 4. Google Discover

- Imagen grande y atractiva (≥1200 px), sin texto encima ni logos invasivos.
- Titular que despierte interés genuino, sin exageración (Discover penaliza el clickbait).
- Temas con interés humano, utilidad o novedad.
- Publicación constante y temas en los que el medio tenga autoridad.

## 5. Google News / Top Stories

- Publicar rápido lo confirmado y **actualizar la misma URL** en vez de crear notas nuevas por cada novedad.
- Mostrar fecha y hora de publicación y de actualización.
- Página de autor con biografía y página de «Quiénes somos» y «Política de correcciones» en el sitio.

## 6. Notas evergreen (tráfico a largo plazo)

Identificar temas que se buscan todo el año y crear guías actualizables: «Cómo sacar [trámite]», «Calendario de feriados [año]», «Qué hacer en caso de sismo». Revisarlas cada 3–6 meses y cambiar la fecha de actualización solo cuando haya cambios reales.

## 7. Errores frecuentes

- Repetir la palabra clave de forma forzada (keyword stuffing).
- Titulares vagos: «Lo que tienes que saber» sin decir de qué.
- Publicar 5 notas casi iguales del mismo hecho (canibalización): mejor una nota fuerte que se actualiza.
- Copiar comunicados textuales: Google prioriza el contenido original. Reescribir, agregar contexto y contraste.

## 8. Formato de entrega

```
TITULAR (H1):
TÍTULO SEO:
META DESCRIPCIÓN:
URL SUGERIDA:
PALABRA CLAVE / SECUNDARIAS:
BAJADA:
CUERPO: (con H2)
CLAVES:
ALT DE IMAGEN:
ENLACES INTERNOS SUGERIDOS:
TAGS:
— CONTROL EDITORIAL —
```
