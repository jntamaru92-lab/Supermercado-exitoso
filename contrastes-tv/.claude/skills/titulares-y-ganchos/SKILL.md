# Titulares y ganchos

**Regla de Contrastes TV:** curiosidad sí, engaño no. El titular promete; la nota cumple.

## 1. Proceso

1. Escribe la noticia en una frase de 10 palabras (la «idea fuerza»).
2. Identifica el **elemento más nuevo, útil o sorprendente**.
3. Genera **5–8 variantes** con fórmulas distintas (abajo).
4. Puntúa cada una con la rúbrica y recomienda 2 para prueba A/B.

## 2. Fórmulas que funcionan

| Fórmula | Ejemplo |
|---|---|
| **Dato + consecuencia** | «La gasolina sube 8 % desde el lunes: así cambia lo que pagas por llenar el tanque» |
| **Pregunta de servicio** | «¿Hay clases mañana? Lo que dijo el Ministerio sobre el paro» |
| **Contraste (insignia)** | «Gobierno dice que bajó el desempleo; los gremios responden con otra cifra» |
| **Número / lista** | «5 cambios del nuevo reglamento de tránsito que te pueden costar una multa» |
| **Quién + qué + dónde** | «Vecinos de [barrio] bloquean la vía por falta de agua desde hace 4 días» |
| **Explicador** | «Qué es [término] y por qué todos hablan de eso» |
| **Primicia / exclusiva** (solo si lo es) | «Exclusivo: el documento que muestra…» |
| **Cita fuerte** (con atribución) | «"No vamos a retroceder": ministro defiende la reforma» |

## 3. Rúbrica (puntúa de 1 a 5)

- **Exactitud:** ¿la nota respalda cada palabra del titular?
- **Claridad:** ¿se entiende sin leer la nota?
- **Interés:** ¿por qué le importa a mi audiencia?
- **Especificidad:** ¿tiene datos concretos (número, lugar, nombre)?
- **SEO / búsqueda:** ¿incluye las palabras que la gente busca? (solo web)

Si **Exactitud < 5**, el titular se descarta sin importar el resto.

## 4. Señales de clickbait prohibido

- Ocultar el dato principal sin razón («No vas a creer lo que pasó»).
- Exagerar («caos total», «destrozó») cuando la nota no lo sostiene.
- Prometer algo que la nota no tiene.
- Usar la tragedia como gancho («Lo que dijo antes de morir…»).

## 5. Ganchos para video (primeros 2 segundos)

El gancho se **dice** y se **escribe en pantalla** a la vez.

- **Resultado primero:** «Desde hoy, el pasaje cuesta 50 centavos más.»
- **Pregunta directa:** «¿Te llegó este mensaje del banco? Es una estafa.»
- **Contraste:** «Unos dicen que es un ahorro; otros, que es un impuesto. Vamos a los datos.»
- **Imagen fuerte + texto:** abrir con la toma más potente, no con el logo.
- **Interpelación local:** «Si vives en [zona], esto te afecta.»

Evitar: «Hola, ¿cómo están? Hoy les traigo…», intros con logo, silencio inicial.

## 6. Longitudes por plataforma

| Lugar | Longitud ideal |
|---|---|
| Titular web (H1) | 55–70 caracteres |
| Post X / Threads | 1 frase fuerte + enlace (≤ 200 caracteres) |
| Facebook | Primeras 1–2 líneas deciden (≈ 125 caracteres visibles) |
| Instagram (caption) | Primera línea ≤ 125 caracteres, el resto en desarrollo |
| Texto en portada de Reel/TikTok | 3–6 palabras, letras grandes |
| Miniatura YouTube | 2–4 palabras, alto contraste |
| Título YouTube | ≤ 70 caracteres, palabra clave al inicio |
| Asunto newsletter | 35–50 caracteres |

## 7. Formato de entrega

```
IDEA FUERZA:
VARIANTES:
1. [titular] — Exactitud 5 · Claridad 4 · Interés 5 · Especificidad 4 · SEO 3
2. …
RECOMENDADAS PARA A/B: #_ y #_ — por qué
COPY POR RED: X / FB / IG / TikTok
TEXTO DE MINIATURA:
```
